Projects

I run a hybrid homelab cluster that spans local bare-metal nodes and free-tier cloud VMs, orchestrated with Nomad, Consul, and Vault. These are tools I built in Go to help me get the most out of free-tier cloud resources I could add to my homelab cluster. The oracle-watchdog and cloudflare-log-collector are pretty simple, but the s3-orchestrator started simple and has since grown into a much larger project with larger goals.

munchbox

The homelab that started it all. A hybrid cloud infrastructure platform running Nomad, Consul, and Vault across local bare-metal nodes and free-tier Oracle Cloud VMs, connected over WireGuard. Everything else on this page grew out of this project.
s3-orchestrator

Unified S3-compatible storage across multiple backends. Stack free-tier allocations from multiple providers into a single endpoint with per-backend quotas, cross-backend replication, and envelope encryption.
cloudflare-log-collector

Cloudflare analytics collector for self-hosted observability stacks. Polls the GraphQL API for firewall events and HTTP traffic stats, ships them to Loki and Prometheus with OpenTelemetry tracing.
oracle-watchdog

Distributed monitoring and recovery for Oracle Cloud free-tier instances. Detects unresponsive nodes via Consul session heartbeats and automatically triggers OCI stop/start cycles.
